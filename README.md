# Coffee-Shop-Sales (Interactive Dashboard creation using MS Excel)

## Project Objective
The Coffee Shop wants to analyze sales data to identify trends and patterns. So that, the owner of the Coffee Shop can understand their customers and grow more sales.

## Dataset used
- <a href="https://github.com/Naikwadifatima-12/Coffee_Shop_Sales/blob/main/Final%20Coffee%20Project.xlsx">Dataset</a>

## Questions (KPIs)
- Compare the sales and orders using single chart.
- Which month got the highest sales and orders?
- Which hour of the day has the highest footfall and sales?
- Which product category generates maximum revenue?
- Which store location is contributing maximum to the sales?
- Relation between product size and revenue generated.
- Which product type is the highest selling?
- Percentage of Total Orders delivered
- Dashboard Interaction <a href="#">View Dashboard</a>

## Process
- Verify data for any missing values and anomalies, and sort out the same.
- Made sure data is consistent and clean with respect to data type, data format and values used.
- Created pivot tables according to the questions asked.
- Merge all pivot tables into one dashboard and apply slicer to make dynamic.

## Project Insight
- **Coffee** is the highest revenue-generating category across all three store locations.
- **Morning hours (7 AM – 11 AM)** see the highest order volume, consistent with typical café peak traffic.
- **Hell's Kitchen and Astoria** outperform Lower Manhattan in overall transaction volume.
- **Weekday footfall** is higher than weekends, suggesting a strong commuter customer base.
- **Large-size** purchases contribute disproportionately to total revenue despite lower quantity share.
- More than **90% of products** were successfully delivered.

## Final Conclusion:
To improve the sales of the Coffee Shop, a strategic marketing plan focused on **morning commuters (7 AM – 11 AM)** across the **Astoria and Hell's Kitchen** locations should be implemented. Since **Coffee** dominates revenue and weekday traffic is highest, targeted promotions such as weekday morning combo deals and loyalty rewards for frequent buyers can significantly boost repeat purchases and average order value. Expanding the **Large-size** upsell strategy across all categories can further maximize revenue per transaction.
